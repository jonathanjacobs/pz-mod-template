# Documentation

The top-level [`README.md`](../README.md) is the public overview. Use [`DOCUMENTATION_OWNERSHIP.md`](DOCUMENTATION_OWNERSHIP.md) to find the authoritative home for any mutable project fact.

## Common routes

- Server operators: [`DEPLOYMENT.md`](DEPLOYMENT.md)
- Contributors: [`REQUIREMENTS.md`](REQUIREMENTS.md), [`ARCHITECTURE.md`](ARCHITECTURE.md), and [`ROADMAP.md`](ROADMAP.md)
- Testers: [`TESTING.md`](TESTING.md) and [`VALIDATION_HISTORY.md`](VALIDATION_HISTORY.md)
- Release maintainers: [`RELEASE_CHECKLIST.md`](RELEASE_CHECKLIST.md) and [`STEAM_WORKSHOP.md`](STEAM_WORKSHOP.md)
- Policy and provenance: [`PZ_MODDING_POLICY.md`](PZ_MODDING_POLICY.md) and [`../COMPLIANCE.md`](../COMPLIANCE.md)

Durable design decisions live under [`adr/`](adr/); bounded experiments live under [`spikes/`](spikes/). [`../CHANGELOG.md`](../CHANGELOG.md) records what changed between releases, [`VALIDATION_HISTORY.md`](VALIDATION_HISTORY.md) records what was observed, and spike documents keep the detailed experimental evidence.
