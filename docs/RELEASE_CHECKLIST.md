# Release checklist

Status: **Not relevant until preparing a release.**

Do not mark a release ready until each applicable item is complete and supported by evidence.

- [ ] `VERSION`, `CHANGELOG.md`, and all applicable `mod.info` files agree.
- [ ] Scope and claims match tested behavior.
- [ ] Required test procedures were run and results recorded in `VALIDATION_HISTORY.md`.
- [ ] Dedicated-server, multiplayer-authority, and save/load behavior were tested where claimed.
- [ ] Package contains no logs, saves, credentials, private configuration, source-control metadata, decompiled source, or extracted game assets.
- [ ] Third-party rights and required attribution are documented.
- [ ] Project Zomboid Modding Policy was reviewed for the intended distribution.
- [ ] Public material clearly presents the mod as unofficial and independent.
- [ ] Workshop/deployment metadata and rollback steps are current.
