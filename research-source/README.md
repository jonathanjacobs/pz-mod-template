# External research material (not committed)

This folder is gitignored (`research-source/` in `.gitignore`). Use it for reference material pulled in from outside the repository, for example:

- `javadocs/` — saved Project Zomboid Javadocs API pages
- `wiki/` — saved/exported community wiki pages
- `notes/` — distilled notes from Reddit, Discord, or other community sources
- `community-mods/` — other Steam Workshop mods, unzipped, kept only to study implementation approaches (never to copy code from)

Per `docs/PZ_MODDING_POLICY.md`, public availability of another mod does not grant redistribution rights. Material here is for learning only; any pattern adopted in this project's own code must be reimplemented independently, not copied. Stable external links belong in [`../docs/RESEARCH_LINKS.md`](../docs/RESEARCH_LINKS.md) instead of here. Remove this folder and its `.gitignore` entry if the project does not need it.
